# Расписание 3БИ1

Сайт с расписанием группы на первое полугодие 2026/2027. Одна страница, без сборщиков
и библиотек: разметка, стили и логика лежат в `index.html`, данные — в `data.json`.

## Что умеет

- три вида: список, неделя, месяц;
- поиск по предметам, преподавателям и аудиториям, фильтры по дню, типу пары,
  подгруппе и нескольким преподавателям сразу;
- подсветка текущей и ближайшей пары, попап дня по клику в неделе и месяце;
- цвет карточки говорит о подгруппе: первая, вторая или общая пара;
- светлая и тёмная темы, погода на день, экспорт недели и месяца в PNG;
- состояние вида и фильтров живёт в адресе страницы — ссылкой можно поделиться.

## Как запустить у себя

```bash
python -m http.server 8731
```

Открыть http://localhost:8731. Файлом из проводника не открывать: `data.json`
загружается через `fetch`, а он требует http.

## Откуда берутся данные

Источник — PDF расписания курса от вуза, он лежит в корне репозитория. Парсер разбирает
таблицу и складывает занятия в JSON:

```bash
python tools/build_from_pdf.py raspisanie-3-kurs_1-polugodie-2026_2027.pdf --group 3БИ1
```

Полезные ключи: `--list` покажет группы в файле, `--all` соберёт данные по всем сразу.
Зависимости — `pip install -r tools/requirements.txt`.

Парсер ничего не решает за деканат: он достаёт поля как есть, а противоречия в таблице
переносит в данные вместе с пояснением. Куда поставить занятие и какое время показать —
решает сайт.

## Ручные правки

Расписание меняется в течение семестра. Чтобы не переписывать таблицу, у занятия есть
два поля прямо в `data.json`:

- `dateOverride` — перенос пары на другую дату;
- `note` — заметка, сайт покажет её значком у пары.

Базовое расписание руками не правим — только этими полями, иначе следующая пересборка
из PDF затрёт изменения.
