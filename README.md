# Расписание 3БИ1

Расписание группы на первое полугодие 2026/2027, собранное из официального расписания курса.

**→ [rediiskka.github.io/raspisanie-3bi1](https://rediiskka.github.io/raspisanie-3bi1/)**

## Что умеет

| | |
|---|---|
| **Сейчас** | подсвечивает текущую пару и показывает ближайшую |
| **Три вида** | список, неделя, месяц — клик по дню открывает его пары |
| **Фильтры** | преподаватель, тип пары, день, подгруппа, поиск по названию |
| **Подгруппы** | цвет карточки говорит, чья пара: первой, второй или общая |
| **Ссылки** | адрес хранит неделю и фильтры — можно скинуть конкретную дату |
| **Картинка** | неделя и месяц скачиваются в PNG, удобно кидать в беседу |
| **Экраны** | телефон, планшет, компьютер |
| **Мелочи** | тёмная тема, погода на сегодня |

## Данные

Собираются из PDF расписания курса программой, а не переписываются руками:

```bash
python tools/build_from_pdf.py <pdf> --group 3БИ1
```

Переносы и предупреждения деканата добавляются к паре отдельно и видны заметкой.

На сайте действует ручная поправка: каждый понедельник у 2-й подгруппы выходной.
При загрузке расписания её пары в этот день убираются, а общие пары понедельника
остаются только у 1-й подгруппы. Исходный PDF и сгенерированный `data.json` не меняются.
